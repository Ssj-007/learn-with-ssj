# About This Blog

Welcome to **Learn with SSJ** — a collection of my learnings and reflections on software engineering, AI, open source, and the technology industry.

## What You'll Find Here

- **AI & Engineering:** Deep dives into how AI is changing software development — code review, kernel generation, and the future of the engineering role.
- **Open Source:** Economics, sustainability, and the structural forces shaping the open source ecosystem.
- **Research Summaries:** Digestible summaries of important papers and industry blog posts, with my own take.

## How This Site Works

This blog is built with [Docusaurus](https://docusaurus.io/) and hosted on GitHub Pages. Each post is a Markdown file in the `blog/` directory. See the [README](https://github.com/Ssj-007/learn-with-ssj) for instructions on how to add new content.
